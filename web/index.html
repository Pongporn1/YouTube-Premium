เว็บส่วนตัวของคุณ

  • Google Sign-In จำกัดหน้าเว็บไว้สำหรับบัญชีที่อนุญาต
  • ฟีด การติดตาม และวิดีโอที่ชอบใช้สิทธิ์ YouTube แบบอ่านอย่างเดียว โดยไม่เก็บ access token ไว้ถาวร
  • API key อยู่ฝั่งเซิร์ฟเวอร์และไม่ถูกส่งเข้าเบราว์เซอร์
  • ดูภายหลังและประวัติ MyTube เก็บใน Local Storage ของโดเมนนี้
  • ข้อมูล YouTube เดิมต้องนำเข้าผ่านลิงก์หรือ Google Takeout
  • ไม่มีฐานข้อมูล MyTube และไม่มีระบบติดตามผู้ใช้
